# 🌍 Adventure Tour Website

A responsive and visually engaging travel website built with **HTML**, **CSS**, and a touch of **JavaScript**. This project showcases upcoming tours, destination highlights, and immersive travel experiences designed to inspire adventure lovers around the world.

## ✨ Features

- Modern, clean UI with mobile-first responsive design
- Sections for:
  - Upcoming Events
  - Exploring Destinations
  - Tours
- Smooth navigation and hover animations
- Minimal JavaScript for interactivity

## 🛠️ Tech Stack

- HTML5
- CSS3 (with Flexbox & Grid)
- JavaScript (for dynamic elements like menu toggle)
